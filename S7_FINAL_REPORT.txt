## KEY DESIGN FEATURES

### 1. ANTI-LOOKAHEAD GUARANTEE (Double Validation)
Strategy enforces two layers of closed-bar-only access:

Layer 1: Feature Preparation
  - prepare_h4_features(df) → applies shift(1) to all outputs
  - prepare_h1_features_with_atr(df) → applies shift(1) to all outputs
  - Result: First bar after warmup has NaN values (not usable)

Layer 2: Data Merging
  - merge_h4_to_m15(df_m15, df_h4) → merge_asof(direction="backward")
  - merge_h1_to_m15_with_atr(df_m15, df_h1) → merge_asof(direction="backward")
  - Result: Each M15 bar only sees historical H4/H1 values, never future data

Verified in tests:
  ✅ test_prepare_h4_features_shift_no_lookahead
  ✅ test_merge_h4_backward_no_future
  ✅ Integration: H4 trend_bias_h4 valid 49/50 bars (first NaN), H1 atr_h1_pips valid 86/100

### 2. UNIT CORRECTNESS
All calculations use consistent units:

H4 (trend direction):
  - EMA crossover: close > ema_fast > ema_slow (no unit conversion)
  - ADX strength: >= adx_min_h4 threshold (dimensionless)
  - Output: trend_bias_h4 in [-1, 0, +1] (dimensionless)

H1 (stop sizing):
  - ATR computed in price units: atr_price = tr.mean()
  - Converted to pips: atr_h1_pips = atr_price / pip_size
  - Used for SL: sl_pips = k_sl_h1 * atr_h1_pips (in pips)
  - Verified: atr_h1_pips ≈ 2 pips for EURUSD 1H (realistic)

M15 (entry timing):
  - Pullback depth in ATR units: pullback_depth = (high - low) / atr_m15
  - Entry on EMA cross: close crosses ema_pullback
  - All normalized to [0, 1] or ATR multiples

Verified in tests:
  ✅ test_prepare_h1_features_with_atr_pips_units → pip conversion working
  ✅ test_s7_sl_points_units_are_pips → SL always in pip units

### 3. GATING STRATEGY (Multi-Layer Risk Control)
Entry requires ALL gates to pass:

Gate 1: H4 Bias Confirmation
  - Condition: trend_bias_h4 != 0
  - Prevents: False entry signals when trend is uncertain
  - Effect: Flat signal when no trend direction

Gate 2: H4 ADX Strength
  - Condition: adx_h4 >= adx_min_h4 (default: 20)
  - Prevents: Trading weak, choppy trends
  - Effect: Flat signal when trend is weak

Gate 3: M15 Pullback Validation
  - Condition: 0.3 <= pullback_depth <= 1.2
  - Prevents: Entries on spikes (pullback_depth > 1.2) or no pullback (pullback_depth < 0.3)
  - Effect: Flat signal when pullback invalid

Gate 4: EMA Slope Alignment
  - Condition: ema_slope_m15 aligns with bias_h4 direction
  - Prevents: Counter-trend entries when M15 EMA already declining
  - Effect: Flat signal when slope misaligned

Verified in tests:
  ✅ test_s7_gating_order → All gates independent
  ✅ test_s7_requires_both_h4_adx_gates → Bias + ADX gates both required

### 4. EXIT STRATEGY
Position management via H1 Chandelier exit:

Stop Loss (Fixed at Entry):
  - Pips: max(k_sl_h1 * atr_h1_pips, min_sl_points)
  - k_sl_h1 = 2.0 (ATR multiplier)
  - min_sl_points = 20 pips (floor)
  - Typical SL: 4-10 pips for EURUSD (2.0 * 2 pips ≈ 4 pips)

Trailing Stop (During Trade):
  - H1 Chandelier exit: high(t) - k*atr_h1 (longs), low(t) + k*atr_h1 (shorts)
  - Moves up (longs) or down (shorts) with price action
  - No fixed take profit (pure trailing)

Verified in tests:
  ✅ test_s7_no_fixed_tp_always_none → TP always None
  ✅ test_s7_sl_from_atr_h1 → SL computed correctly
